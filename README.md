# Programming Problems & Solutions

## Overview

This repository contains solutions to 20 programming problems covering fundamental programming concepts, string manipulation, array operations, mathematical calculations, and problem-solving techniques.

The problems are implemented using JavaScript and focus on developing logical thinking, writing clean code, and understanding common algorithmic approaches.

## Technologies Used

- JavaScript
- Problem Solving
- Algorithms and Data Structures
- Array and String Manipulation
- Loops and Conditional Statements

## Problem List

### Problem 1: Staircase
Construct a right-aligned staircase of height `n` using spaces and `#` characters.

**Example:**
- Input: `n = 4`
- Output:
  ```text
     #
    ##
   ###
  ####
  ```

### Problem 2: Grading Students
Round student grades according to the specified grading rules. Grades below 38 remain unchanged.

**Example:**
- Input: `[73, 67, 38, 33]`
- Output: `[75, 67, 40, 33]`

### Problem 3: Time Conversion
Convert a time from 12-hour AM/PM format to 24-hour format.

**Example:**
- Input: `"07:05:45PM"`
- Output: `"19:05:45"`

### Problem 4: String Repeat
Repeat a given string exactly `n` times.

**Example:**
- Input: `n = 3, s = "ha"`
- Output: `"hahaha"`

### Problem 5: Reversed Strings
Return a new string containing the characters of the original string in reverse order.

**Example:**
- Input: `"world"`
- Output: `"dlrow"`

### Problem 6: Sum of Positive
Calculate the sum of all positive numbers in an array, ignoring zero and negative numbers.

**Example:**
- Input: `[1, -4, 7, 12]`
- Output: `20`

### Problem 7: Grasshopper — Summation
Calculate the sum of all integers from 1 through a given positive integer `num`.

**Example:**
- Input: `num = 8`
- Output: `36`

### Problem 8: Convert a Boolean to a String
Convert a Boolean value into its string representation.

**Example:**
- Input: `true`
- Output: `"true"`

### Problem 9: Fizz Buzz
Generate a sequence from 1 to `n`, replacing multiples of 3 with `"Fizz"`, multiples of 5 with `"Buzz"`, and multiples of both with `"FizzBuzz"`.

**Example:**
- Input: `n = 5`
- Output: `["1", "2", "Fizz", "4", "Buzz"]`

### Problem 10: Running Sum of 1D Array
Calculate the running sum of an array, where each element represents the sum of all elements up to that index.

**Example:**
- Input: `[1, 2, 3, 4]`
- Output: `[1, 3, 6, 10]`

### Problem 11: Richest Customer Wealth
Calculate each customer's total wealth and return the maximum wealth among all customers.

**Example:**
- Input: `[[1, 2, 3], [3, 2, 1]]`
- Output: `6`

### Problem 12: Remove Duplicates from Sorted Array
Remove duplicate values from a sorted array in-place and return the number of unique elements.

**Example:**
- Input: `[1, 1, 2]`
- Output: `k = 2`, with the first two elements being `[1, 2]`.

### Problem 13: Contains Duplicate
Determine whether an array contains any duplicate values.

**Example:**
- Input: `[1, 2, 3, 1]`
- Output: `true`

### Problem 14: Move Zeroes
Move all zeros to the end of an array while preserving the relative order of non-zero elements. Modify the original array in-place.

**Example:**
- Input: `[0, 1, 0, 3, 12]`
- Output: `[1, 3, 12, 0, 0]`

### Problem 15: Merge Sorted Array
Merge two sorted arrays into the first array in-place, maintaining non-decreasing order.

**Example:**
- Input: `nums1 = [1, 2, 3, 0, 0, 0]`, `nums2 = [2, 5, 6]`
- Output: `[1, 2, 2, 3, 5, 6]`

### Problem 16: 3Sum
Find all unique triplets in an integer array whose sum equals zero.

**Example:**
- Input: `[-1, 0, 1, 2, -1, -4]`
- Output: `[[-1, -1, 2], [-1, 0, 1]]`

### Problem 17: Plus One
Increment a non-negative integer represented as an array of digits by one and return the resulting digit array.

**Example:**
- Input: `[1, 2, 9]`
- Output: `[1, 3, 0]`

### Problem 18: Reverse String
Reverse an array of characters in-place without creating another array for the reversed result.

**Example:**
- Input: `["h", "e", "l", "l", "o"]`
- Output: `["o", "l", "l", "e", "h"]`

### Problem 19: Length of Last Word
Return the length of the last word in a string, ignoring leading, trailing, and repeated spaces.

**Example:**
- Input: `"Hello World"`
- Output: `5`

### Problem 20: Longest Common Prefix
Find the longest prefix shared by every string in an array. Return an empty string if no common prefix exists.

**Example:**
- Input: `["flower", "flow", "flight"]`
- Output: `"fl"`
